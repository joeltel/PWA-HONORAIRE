HONORAIRE V5 — Pack PWA

Contenu :
- index.html (version PWA de ton fichier)
- manifest.webmanifest
- service-worker.js
- icons/ (icônes 192/512 + maskable)

Usage :
1) Mets tout le dossier sur un serveur (HTTPS) ou lance un serveur local.
   Exemple : `python -m http.server 8080`
2) Ouvre http://localhost:8080 puis "Installer" dans le navigateur.

Note :
Les Service Workers ne fonctionnent pas en ouvrant le fichier en double-clic (file://).
